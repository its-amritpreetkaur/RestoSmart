# 🍽️ RestoSmart — Restaurant Management System

**RestoSmart** is a desktop-based restaurant management system built to streamline daily operations, table reservations, menu organization, billing, and real-time order processing. Developed using **Visual Studio (.NET/C#)** with an **Oracle Database** backend, it provides a centralized platform for staff and administrators to handle restaurant workflows efficiently.
---

## ✨ Key Features

- **📋 Order Management System:** Real-time order placement, item customization, table-to-order mapping, and status tracking (Pending, In-Kitchen, Served).
- **💳 Automated Billing & Invoicing:** Instant bill generation with automated tax calculations, discounts, and itemized invoice printing.
- **🥘 Menu & Inventory Control:** Add, update, and manage categories, menu items, pricing, and stock availability.
- **📊 Table Reservation & Allocation:** Dynamic table status views (Available, Occupied, Reserved) to reduce wait times and optimize floor capacity.
- **🔒 Role-Based Access Control:** Secure login mechanisms for administrative staff, managers, and cashiers.
- **💾 Relational Database Integration:** Robust data storage and retrieval powered by Oracle Database with optimized PL/SQL procedures and triggers.

---

## 🛠️ Tech Stack & Architecture

- **Development IDE:** Visual Studio
- **Language / Framework:** C# / .NET (Windows Forms / WPF)
- **Database:** Oracle Database (PL/SQL, Tables, Stored Procedures, Triggers)
- **Data Access:** ADO.NET / Oracle Data Provider for .NET (ODP.NET)
- **UI Design & Assets:** Custom UI components & Figma prototyping
